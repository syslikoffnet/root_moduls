Импорт из Happ

      
Скопируйте в Happ ссылку подписки (или сами строки vless://) и вставьте ниже. Base64-подписки понимаются автоматически.

      
      
      
    

    
Подписки (класс + URL)

      
      
      
wifi — на Wi-Fi, mobile — на мобильной, all — всегда. Кэш нод обновляется каждые 6 ч.

    

    
Свой прокси (приоритетнее подписок)

      
      
      
Публичные ноды видят трафик к доменам из списка — для чувствительного укажите свой сервер.

    

  


  

    
На какие приложения действует

      

        
        
        
      

      
      

      
      
      
exclude — удобно для банков/госуслуг; include — минимальная нагрузка: проксируется только то, что нужно. Батарея: include экономичнее всего.

    

  


  

    
Домены геоблока (в прокси)

      
      
      
DPI-блокировки (YouTube и т.п.) сюда класть не нужно — их лечит zapret2. Изменения применяются сами за ~90 сек.

Ручных нод—

      
sing-box в TPROXY/REDIRECT (без TUN). Рунет и DPI-обход zapret2 не затрагиваются. Сбой всех нод → правила снимаются мгновенно, интернет прямой (fail-open). Экономия батареи: urltest спит при простое, проверка здоровья раз в 90 с, никаких цикличных опросов сети.
